# Averan

Averan operations and technology consultancy website, built with Next.js.

## Development

Run `npm ci`, then `npm run dev`. Run `npm run build` before deploying.

## Contact

Public email: info@averan.eu. The call form stays disabled until the webhook and Turnstile environment variables in `.env.example` are configured. Email link availability does not verify mailbox delivery.

## Verification

Run `node tests/contact-handler.mjs` and `npm run build`.

The privacy and cookie pages are provisional notices and need final business/provider details. See DEPLOYMENT.md for contact-delivery configuration.
